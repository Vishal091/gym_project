# GymPilot — Android

Android app for a small-gym management SaaS, built with Kotlin and Jetpack Compose.

## MVP scope
- Owner dashboard with membership and payment summaries
- Member directory and member profiles
- Attendance check-ins
- Membership expiry and fee due tracking
- UI currently uses local demo data; backend authentication and sync will be connected in a later phase.

## Requirements
- Android Studio (current stable)
- JDK 17+

## Build
Open this repository in Android Studio and sync Gradle. Select the `app` run configuration and launch on an emulator or Android device.

## Security note
Do not commit API keys, signing keys, passwords, or customer data.
